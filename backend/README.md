# Общий доступ команды

Фронтенд остаётся на GitHub Pages; сервер — Cloudflare Worker `demitask-api`.

`worker.js` не содержит секретов. В Cloudflare → Worker → Settings → Variables and Secrets добавляются **два Secret**:

- `GROQ_API_KEY` — ключ владельца Groq.
- `TEAM_CODE` — длинный случайный код входа команды (не API-ключ).

После этого `config.js` содержит только публичный URL Worker. Коллега один раз вводит код команды; подписанная сессия хранится в sessionStorage этой вкладки до 12 часов и переживает обновление страницы. Сервер не возвращает API-ключ пользователю. Изменение TEAM_CODE аннулирует выданные сессии. Срок самого ключа задаётся в Groq; его нужно заменять на сервере после истечения.

Разрешены только `/session`, `/health`, `/chat/completions` и `/audio/transcriptions`. Запросы ограничены разрешёнными моделями, размером тела и числом выходных токенов; сервер не является произвольным сетевым прокси. Origin проверяется дополнительно, но не заменяет авторизацию. Встроенные счётчики запросов — best effort на экземпляр Worker; они не гарантируют общий лимит при нескольких экземплярах. Жёсткие общие квоты применяет Groq Free. Не включайте платный тариф провайдера без отдельного ограничения расходов; для роста нагрузки нужны распределённый лимитер и индивидуальные учётные записи.

Проверка без секрета: `/health` отвечает 503. С секретами и разрешённым Origin — `{ "ready": true }`. Без корректной сессии API отвечает 401, с посторонним Origin — 403. CORS-проверка требует Origin, поэтому прямой переход по URL в браузере не является проверкой готовности API.

На бесплатном Cloudflare Workers сейчас включено 100 000 запросов в день. Groq Free имеет собственные лимиты по запросам, токенам и аудио. Для примерно 50 задач в месяц ожидается достаточный запас, если задачи не запускаются большим пакетом одновременно. Точные квоты и доступность уточняются в консоли провайдера.

Распознавание браузером используется по умолчанию и не обращается к Worker/Groq. Whisper — выбираемый пользователем резерв, который расходует бесплатную аудиоквоту Groq. Текст задач, словарь и ответы проходят через Cloudflare в Groq; в режиме Whisper тем же путём проходит аудио. Код не записывает их в серверное хранилище и не логирует тела запросов.

Сервер развёрнут из этого же файла через редактор Cloudflare. После изменения `worker.js` обновите код Worker и нажмите Deploy; push GitHub сам по себе пока обновляет только Pages. Перед заменой серверного ключа убедитесь, что выбран тип Secret, а не обычный Text.

Документация: https://developers.cloudflare.com/workers/configuration/secrets/ и https://console.groq.com/docs/rate-limits
