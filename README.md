# ДемиТаск

Веб-прототип постановщика задач для Битрикс24. Голосовая или текстовая мысль превращается в название с конечным продуктом, подробное описание и отдельные чек-листы. Светлый интерфейс с холодными красными акцентами, адаптивный для телефона.

## Возможности

- Название: **Подготовить баннер (ЦКП: баннер согласован и передан на размещение)**.
- **Умная постановка** задаёт до трёх вопросов по недостающим существенным деталям; без галочки сразу создаётся черновик с пометками о пробелах.
- Материнская задача и самостоятельные подзадачи по переключателю.
- Копирование полного названия, ЦКП, описания с HTML-форматированием, названия чек-листа, всех пунктов и каждого пункта отдельно.
- Редактирование готовых задач, JSON-экспорт, история последних 12 результатов.
- Редактируемый регламент и словарь терминов: название, варианты произношения, пояснение.
- Без полей сроков и исполнителей.
- Справка по кнопке «?».

## Запуск

Нужен Node.js 20+; сторонних npm-зависимостей нет.

```sh
npm start
```

Откройте http://127.0.0.1:4173. Для другой машины запустите собственный статический HTTPS-хостинг; сервер разработки слушает только loopback.

```sh
npm test
```

## Нейросеть и бесплатный API

По умолчанию включён **деморежим без сетевых запросов**. Он демонстрирует интерфейс, вопросы и структуру по фиксированному шаблону. Используйте «Попробовать на примере». Произвольный текст в деморежиме только помещается в шаблон, а не осмысливается нейросетью.

Для настоящей обработки:

1. Создайте свой ключ на [Groq → API Keys](https://console.groq.com/keys).
2. Откройте «Подключение AI» и вставьте ключ в поле внутри приложения.
3. Выберите модель и нажмите «Подключить Groq». Ключ проверяется первым запросом.

Базовая модель — `openai/gpt-oss-120b`; доступны `openai/gpt-oss-20b` и `qwen/qwen3.8-27b`. Запрос использует строгий JSON Schema, результат дополнительно проверяется в приложении. Текст, ответы, регламент и словарь передаются напрямую Groq. Неполный ответ или ошибка API не подменяются деморезультатом.

По [документации Groq](https://console.groq.com/docs/rate-limits), проверенной 14 октября 2026, базовая бесплатная квота GPT OSS 120B — до 30 запросов/мин, 1 000 запросов/день, 8 000 токенов/мин и 200 000 токенов/день. Лимиты действуют одновременно; расходуются и входные, и выходные токены, поэтому фактическое число задач может быть меньше. Точные ограничения своего аккаунта смотрите в [Limits](https://console.groq.com/settings/limits). Доступность сервиса и моделей зависит от региона и аккаунта; бесплатный тариф не означает безлимитный API. Если модель снята с обслуживания, выберите другую поддерживаемую в настройках и обновите список в коде.

### Голос

С Groq: `MediaRecorder` → `whisper-large-v3-turbo`, язык `ru`, до 3 минут записи; названия из словаря передаются как подсказка. Поддерживаемый аудиоформат выбирается браузером, затем распознавание дополняет исходный текст. Документация: [Speech to Text](https://console.groq.com/docs/speech-to-text). На бесплатном тарифе лимит файла 25 МБ; текущие аудиоквоты смотрите в консоли.

Без ключа: Web Speech API, если браузер его поддерживает. Распознавание может использовать внешний сервис браузера и не гарантируется на всех платформах. При отсутствии поддержки приложение предлагает Groq или текстовый ввод. Требуются HTTPS либо localhost и разрешение на микрофон.

## Ключи и данные

Это личный прототип с **собственным ключом пользователя**. Ключ живёт только в JS-памяти вкладки, используется в заголовке Authorization для api.groq.com и удаляется при перезагрузке/переходе в деморежим. Ключ не сохраняется в Git, localStorage, истории или экспортируемой задаче. Его не следует присылать в чат или добавлять в файлы проекта.

Черновик, регламент, словарь и история хранятся в localStorage этого браузера. Они не синхронизируются между устройствами и не публикуются вместе с кодом. Очищая данные сайта, вы удаляете эти записи. На общей машине учитывайте, что эти локальные данные доступны пользователям того же профиля браузера.

В режиме Groq исходный текст, ответы, регламент и словарь отправляются провайдеру, а при распознавании — ещё и аудиозапись. Сырой звук приложение в хранилище не записывает. Страница загружает шрифт из Google Fonts с системным запасным вариантом.

Для общего сервиса с единым служебным ключом необходим отдельный серверный прокси с авторизацией и ограничением запросов. **GitHub Pages не выполняет серверный код и не хранит серверные секреты.** Общий ключ нельзя встраивать в JavaScript или GitHub Actions для подстановки в публичный HTML. В текущем прототипе каждый пользователь вводит собственный ключ.

## GitHub Pages

Сайт полностью статический, все ссылки на ресурсы относительные. Можно опубликовать корень ветки `main` в Settings → Pages → Deploy from a branch. Файл `.nojekyll` отключает обработку Jekyll. Не нужен этап сборки или переменные окружения.

GitHub Actions запускает модульные тесты на push и pull request. Микрофон и реальный ответ Groq нужно дополнительно проверить в целевом браузере со своим ключом. Приложение копирует HTML и обычный текст в буфер; поведение вставки зависит от редактора Битрикс24 и настроек браузера. При запрете HTML-буфера есть явный переход на обычный текст. Прямой интеграции с API Битрикс24 нет.

## Структура

- `index.html`, `style.css` — интерфейс и адаптивная палитра.
- `app.js` — состояние, Groq, микрофон, локальное хранение, буфер обмена.
- `core.js` — регламент, схема ответа, словарь, безопасное HTML-представление, демонстрационные данные.
- `tests/core.test.mjs` — проверка структуры, режимов, словаря и защиты HTML от внедрения разметки.
- `server.mjs` — локальный сервер без зависимостей.
