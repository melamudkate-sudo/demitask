# ДемиТаск

Веб-прототип постановщика задач для Битрикс24. Голосовая или текстовая мысль превращается в название с конечным продуктом, подробное описание и отдельные чек-листы. Светлый интерфейс с холодными красными акцентами, адаптивный для телефона.

## Возможности

- Название: **Подготовить баннер (ЦКП: баннер согласован и передан на размещение)**.
- **Умная постановка** задаёт до трёх вопросов по недостающим существенным деталям; без галочки сразу создаётся черновик только по известным данным, без заглушек.
- Материнская задача и самостоятельные подзадачи по переключателю.
- Копирование полного названия, ЦКП, описания с HTML-форматированием, названия чек-листа, всех пунктов и каждого пункта отдельно.
- Редактирование готовых задач, история последних 12 результатов.
- Редактируемый регламент и словарь терминов: название, варианты произношения, пояснение.
- Без полей сроков и исполнителей.
- Справка по кнопке «?», включая голосовые ответы и оценку понятности.
- Зелёный/жёлтый/красный индикатор: пояснения во всплывающем окне и выделение фраз внутри текста, без изменения высоты карточек или автоматической прокрутки. Пробелы не добавляются в копируемое описание. Оценку формирует нейросеть; для деморежима и старой истории используется локальная проверка структуры. Это оценка формулировки, не гарантия качества.

## Запуск

Нужен Node.js 20+; сторонних npm-зависимостей нет.

```sh
npm start
```

Откройте http://127.0.0.1:4173. Для другой машины запустите собственный статический HTTPS-хостинг; сервер разработки слушает только loopback.

```sh
npm test
```

## Нейросеть и бесплатный API

Если командный сервер не настроен, используется **деморежим без сетевых запросов**. Он демонстрирует интерфейс, вопросы и структуру по фиксированному шаблону. Скачивания задачи в JSON нет. Используйте «Попробовать на примере». Произвольный текст в деморежиме только помещается в шаблон, а не осмысливается нейросетью.

Для командного режима коллеги используют код команды, а ключ владельца хранится как Secret в Cloudflare Worker. Код доступа подходит для команды из 20 человек; квота общая. Публичный адрес сервера задан в `config.js`; сервер описан в [backend/README.md](backend/README.md). Сессия команды сохраняется в этой вкладке на 12 часов, поэтому после обычного обновления личный API-ключ вводить не нужно.

Для индивидуального прототипа без настроенного командного сервера:

1. Создайте свой ключ на [Groq → API Keys](https://console.groq.com/keys).
2. Откройте «Подключение AI» и вставьте ключ в поле внутри приложения.
3. Выберите модель и нажмите «Подключить Groq». Ключ проверяется первым запросом.

Базовая модель — `openai/gpt-oss-120b`; доступны `openai/gpt-oss-20b` и `qwen/qwen3.8-27b`. Запрос использует строгий JSON Schema, результат дополнительно проверяется в приложении. Текст, ответы, регламент и словарь передаются напрямую Groq. Неполный ответ или ошибка API не подменяются деморезультатом.

По [документации Groq](https://console.groq.com/docs/rate-limits), проверенной 14 октября 2026, базовая бесплатная квота GPT OSS 120B — до 30 запросов/мин, 1 000 запросов/день, 8 000 токенов/мин и 200 000 токенов/день. Лимиты действуют одновременно; расходуются и входные, и выходные токены, поэтому фактическое число задач может быть меньше. Точные ограничения своего аккаунта смотрите в [Limits](https://console.groq.com/settings/limits). Доступность сервиса и моделей зависит от региона и аккаунта; бесплатный тариф не означает безлимитный API. Если модель снята с обслуживания, выберите другую поддерживаемую в настройках и обновите список в коде.

### Голос

С Groq: `MediaRecorder` → `whisper-large-v3-turbo`, язык `ru`, без прежнего автостопа на 3 минутах и без обрезки текста до 14 000 символов. Каждые 60 секунд стартует новый MediaRecorder, предыдущий останавливается через 1,2 секунды: это сохраняет звук на границе фрагментов. Каждый фрагмент — отдельный воспроизводимый файл, а не невалидный срез WebM. Транскрипции обрабатываются по очереди, склеиваются по порядку с консервативным удалением совпадающих слов на стыке; названия из словаря передаются как подсказка. Поддерживаемый аудиоформат выбирается браузером, затем распознавание дополняет исходный текст. Документация: [Speech to Text](https://console.groq.com/docs/speech-to-text). На бесплатном тарифе лимит файла 25 МБ; текущие аудиоквоты смотрите в консоли.

Голосовой ввод доступен как для исходной задачи, так и для каждого уточняющего ответа. Есть таймер записи и счётчик готовых фрагментов. После остановки следует дождаться обработки очереди. Ограничения Groq по размеру файла, квотам и длине запроса остаются; текст при их достижении не обрезается, сервис показывает ошибку.

По умолчанию для всех режимов: бесплатный Web Speech API, если браузер его поддерживает. Он не требует API-ключа и не расходует квоту Groq; встроенный сервис браузера может обрабатывать речь на своих серверах. Выбора провайдера в интерфейсе нет: при отсутствии поддержки или ошибке сервиса браузера включается Whisper через бесплатную аудиоквоту Groq. При переключении показано уведомление с просьбой повторить последнюю фразу; уже распознанный текст сохраняется.

Web Speech API: Сохраняются промежуточные результаты, включая последнюю незавершённую фразу; при штатном окончании сессии распознавание перезапускается до остановки пользователем. Распознавание может использовать внешний сервис браузера и не гарантируется на всех платформах. При отсутствии поддержки приложение использует резервное распознавание через общий доступ команды; без подключённой команды предлагает войти. Требуются HTTPS либо localhost и разрешение на микрофон.

Оценка понятности открывает причины во всплывающем окне поверх страницы. Замечания выделяют фразы прямо в тексте; подсветка не меняет размеры карточки и не прокручивает страницу.

## Ключи и данные

В индивидуальном режиме используется **собственный ключ пользователя**. Ключ живёт только в JS-памяти вкладки, используется в заголовке Authorization для api.groq.com и удаляется при перезагрузке/переходе в деморежим. Ключ не сохраняется в Git, localStorage, истории или файлах. Его не следует присылать в чат или добавлять в файлы проекта.

Черновик, регламент, словарь и история хранятся в localStorage этого браузера. Они не синхронизируются между устройствами и не публикуются вместе с кодом. Очищая данные сайта, вы удаляете эти записи. На общей машине учитывайте, что эти локальные данные доступны пользователям того же профиля браузера.

В режиме Groq исходный текст, ответы, регламент и словарь отправляются провайдеру, а при распознавании — ещё и аудиозапись. Сырой звук хранится только в памяти открытой вкладки и доступен для прослушивания и скачивания по фрагментам; при новой записи предыдущий набор заменяется. Он не сохраняется в localStorage и исчезает после закрытия/перезагрузки вкладки. При ошибке распознавания исходный фрагмент остаётся доступен для повтора. Нераспознанные фрагменты не пропускаются молча: сборка блокируется до повтора либо явного выбора распознанной части. Страница загружает шрифт из Google Fonts с системным запасным вариантом.

Для общего сервиса с единым служебным ключом добавлен серверный прокси с авторизацией по коду команды и ограничениями запросов — см. `backend/`. **GitHub Pages не выполняет серверный код и не хранит серверные секреты.** Общий ключ нельзя встраивать в JavaScript или GitHub Actions для подстановки в публичный HTML. В командном режиме API-ключ не передаётся в браузеры коллег.

## GitHub Pages

Сайт полностью статический, все ссылки на ресурсы относительные. Можно опубликовать корень ветки `main` в Settings → Pages → Deploy from a branch. Файл `.nojekyll` отключает обработку Jekyll. Не нужен этап сборки или переменные окружения.

GitHub Actions запускает модульные тесты на push и pull request. Микрофон и реальный ответ Groq нужно дополнительно проверить в целевом браузере со своим ключом. Приложение копирует HTML и обычный текст в буфер; поведение вставки зависит от редактора Битрикс24 и настроек браузера. При запрете HTML-буфера есть явный переход на обычный текст. Прямой интеграции с API Битрикс24 нет.

## Структура

- `index.html`, `style.css` — интерфейс и адаптивная палитра.
- `app.js` — состояние, Groq, микрофон, локальное хранение, буфер обмена.
- `core.js` — регламент, схема ответа, безопасное HTML-представление и деморежим.
- `glossary.js` — публичный словарь DEMIAND с источниками, вариантами произношения, ограниченными русскими падежными формами и миграцией без Luna. Индивидуальные термины пользователей хранятся только в браузере. Удалённые пользователем базовые записи учитываются при миграциях. Автоматическая нормализация не является полным морфологическим анализатором; нерегулярные формы можно явно добавить как варианты, а нейросеть получает весь словарь.
- `voice.js` — сегментированная запись и сборка расшифровок.
- `quality.js` — схема оценки и проверка указателей подсветки.
- `rich-text.js` — безопасное оформление редактируемого описания: разрешённые теги без атрибутов, обычный текст для буфера.

Готовый текст можно редактировать в карточке с жирностью, курсивом, подчёркиванием и списками. Правки с ИИ получают текущую ручную версию и сохраняют исходную задачу до нажатия «Применить правки». Черновик предложения не подменяет задачу автоматически.
- `tests/` — 28 проверок структуры, режимов, словаря, миграций, оценки качества, полного длинного текста, последних слов и завершения всех звуковых фрагментов.
- `server.mjs` — локальный сервер без зависимостей.
